# Prueba Sencilla con Streamlit

Una aplicación web interactiva desarrollada en **Python** utilizando **Streamlit**, diseñada para analizar estadísticas de texto en tiempo real y aplicar transformaciones de manera rápida y sencilla.

Puedes probar la aplicación en línea aquí: 👉 [Ver App en Streamlit Cloud](https://prueba-app-pvm6w4qzjvmryhn7trmnkb.streamlit.app/)

---

##  Características

* **Contadores en vivo:** Calcula el número total de palabras y caracteres de cualquier texto ingresado.
* **Interfaz intuitiva:** Diseñada completamente en Python utilizando widgets modernos y organizados en columnas.

---

## 🛠️ Tecnologías Utilizadas

* **Python** (Lógica principal)
* **Streamlit** (Interfaz de usuario web)
